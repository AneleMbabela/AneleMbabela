# HabitFlow

A lightweight, responsive habit tracker built with vanilla HTML, CSS and JavaScript.

## Features
- Add and delete habits
- Daily completion tracking
- Current and best streaks
- Completion statistics
- All / Active / Completed filters
- Light and dark themes
- Local browser storage — no account or backend required
- Responsive mobile and desktop UI

## Run locally
Open `index.html` in a browser, or serve the `habit-tracker` folder with any static web server.

## GitHub Pages
The repository workflow deploys this folder to GitHub Pages automatically when changes land on `main`.

Your data is stored locally in your browser using `localStorage`.
